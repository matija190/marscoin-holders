Data source

Our own Marscoin full node (Marscoin Core 28.x). Balances are aggregated from the complete UTXO set; "circulating" is the sum of all unspent outputs (gettxoutsetinfo). The unspendable genesis reward and provably burned outputs are excluded.

Holder list

The holder list contains every address holding at least 100 MARS (… addresses at block …), ranked by balance. Addresses holding less than 100 MARS are not listed individually, but they are included in the supply, distribution and concentration figures.

Labels

Labels are only shown where the owner is publicly documented or verifiable on-chain.

Public API (plain text, CoinGecko / CMC compatible)
  • GET /api/supply/circulating…
  • GET /api/supply/totalsame as circulating
  • GET /api/supply/max…
  • GET /api/supplyJSON: all values + height
  • ?format=json{"result":"…"} for single values
  • GET /api/address/<address>balance, rank, activity of any address
  • GET /api/holders?page=&per_page=&q=&sort=holder list, paginated (JSON)
  • GET /data/data.jsonsupply, distribution, statistics
  • GET /data/holders.jsonevery address holding 100 MARS or more
